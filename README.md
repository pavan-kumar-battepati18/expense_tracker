# Personal Finance Tracker 💰

A Python-based CLI expense tracker with real-time 
Telegram push notifications on every transaction.

## Features
- Add expenses and income
- Instant Telegram notification on every transaction
- CSV based persistent storage
- Daily and total summary with balance

## Tech Stack
Python | Telegram Bot API | REST API | CSV

## Setup
1. Clone the repo
2. pip install requests
3. Add your BOT_TOKEN and CHAT_ID in expense_tracker.py
4. python expense_tracker.py# expense_tracker
